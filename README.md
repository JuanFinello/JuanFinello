## What I'm working on (2026)

Most of my current work lives in private repositories (employer code). This is what is in them:

**Publication ↔ sequence linking pipeline** · Python, SQLite, Nextflow, Crossref / PubMed / OpenAlex / GISAID APIs
Replaces a manual daily process: ingests newly published scientific articles, extracts the genomic accession identifiers they report and links them to the corresponding sequences across 12 pathogen databases. Over 100,000 articles processed; extraction validated against a manually curated ground truth (F1 ≈ 97%).

**LLM-based preprint triage** · Python, GPT / Claude / DeepSeek APIs
Scores preprints against a five-criterion editorial rubric before they reach the curation queue. The three models are benchmarked against expert manual scoring, and the scores feed the daily pipeline.

**Arbovirus genomics dashboard** · SQLite, Metabase, Docker
A SQL data model that consolidates publications, genomic accessions, institutions and journals, plus a self-service BI dashboard used by management to track who publishes with GISAID data, where samples originate and how open-data adoption evolves.
